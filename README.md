# Intrusion Detection System (IDS)

A Python-based **Intrusion Detection System (IDS)** project designed to monitor network activity, analyze suspicious traffic, and present security insights through a clean web-based dashboard interface.

This project focuses on understanding IDS concepts, packet analysis, traffic monitoring, and real-time visualization using Python and web technologies.

## Features

- Network traffic monitoring
- Python-based IDS implementation
- Web dashboard for live traffic visualization
- JSON-based log handling
- Suspicious activity detection
- Simple and interactive UI
